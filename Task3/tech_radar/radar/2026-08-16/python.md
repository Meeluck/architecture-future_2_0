Python остаётся основным языком медицинских ИИ-сервисов и допустим для доменных data jobs.

**Бизнес-сценарии:** BS2, BS4.

**Почему Adopt:** язык уже используется командой ИИ и имеет подходящую экосистему. Переписывание без измеримой причины увеличит риск и не улучшит архитектурные границы.

Модели должны иметь реестр версий, наблюдаемость качества и контролируемый выпуск. Медицинские данные обрабатываются в отдельном защищённом контуре.
