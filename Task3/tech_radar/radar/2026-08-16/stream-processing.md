Специализированная обработка событий с задержкой в секунды для выбранных операционных или технических сценариев.

**Бизнес-сценарии:** BS3, BS4, BS5.

**Почему Assess:** большинству отчётов достаточно batch/CDC. Real-time для всех наборов увеличит стоимость и сложность без пропорциональной пользы.

Кандидат переводится в Trial, если владелец процесса подтвердит допустимую задержку, цену опоздания и объём потока, например для критичной телеметрии оборудования.
