Java сохраняется для существующих и новых финтех-сервисов, где команда уже умеет обеспечивать надёжность, тестирование и поддержку.

**Бизнес-сценарии:** BS2, BS5.

**Почему Adopt:** архитектурная проблема находится в общей модели данных и связности систем, а не в языке финтех-сервисов.

Новые сервисы соблюдают доменные границы, версионируемые API/events, идемпотентность критичных операций и требования аудита.
