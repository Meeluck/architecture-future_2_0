Стандартный интеграционный вход вместо добавления новых маршрутов в старую ESB: API для запросов, broker для событий, CDC/batch для аналитики и миграции.

**Бизнес-сценарии:** BS2, BS3, BS6.

**Почему Trial:** на пилоте нужно провести одну интеграцию клиника–финтех, одну выгрузку из DWH и onboarding нового домена.

Конкретные продукты gateway, broker и CDC-коннектора выбираются отдельным ADR после проверки требований и навыков команды.
