API используется для запроса с немедленным ответом, события — для публикации факта, batch и CDC — для аналитики и постепенной миграции.

**Бизнес-сценарии:** BS2, BS3, BS6.

**Почему Adopt:** стабильный контракт отделяет внутреннюю модель домена от потребителей. Фарма или оборудование подключаются без изменения процедур SQL Server 2008.

Несовместимое изменение должно создавать новую версию и проходить автоматическую проверку схемы.
