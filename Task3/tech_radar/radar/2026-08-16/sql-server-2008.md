SQL Server 2008 временно остаётся системой учёта и источником разрешённых CDC/batch-выгрузок, но новые процедуры, витрины и интеграционная логика в нём не создаются.

**Бизнес-сценарии:** BS1, BS2, BS3, BS6.

**Почему Hold:** устаревшая общая БД совмещает операционную, ETL- и BI-нагрузку, плохо масштабируется и связывает релизы доменов.

Вывод идёт по потребителям после сверки нового data product. Полное отключение одним переключением не требуется.
